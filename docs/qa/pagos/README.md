# Evidencia visual de pagos

Esta carpeta conserva las capturas de referencia de la vista de pagos y el HTML de previsualización que antes estaban en la raíz del proyecto. Son artefactos de QA; no forman parte de la aplicación ni representan una captura posterior a los últimos ajustes.

El archivo `.qa-pagos.html` reutiliza `css/nueva.css` desde la raíz del repositorio.
