# Imágenes de servicios

La propiedad `logo` de cada entrada de `SERVICIOS` en [servicios.js](../../js/nueva/servicios.js) contiene el nombre completo del archivo. Las tarjetas de SUNARP declaran su imagen directamente en [app.html](../../app.html).

Al reemplazar una imagen, actualiza la referencia en el mismo cambio. El navegador carga la extensión escrita en el nombre.
